# Freezer Manager — frontend

Angular 22 app. See the [project README](../README.md) for how to run everything, and
[docs/architecture.md](../docs/architecture.md#frontend) for the structure.

```bash
npm install
npm start                    # http://localhost:4200, proxies /api to the backend on :8080
npm test -- --watch=false    # unit tests (Vitest)
npm run build
```
